# Fork 定制修改说明

本文档记录本仓库相对上游 [morethanwords/tweb](https://github.com/morethanwords/tweb) 的**自有定制**，便于后续合并上游、排查问题或交接时查阅。未列出的文件与官方主线行为一致（或仅存在无意义的格式化差异）。

---

## 一、语言与中文体验（核心）

### `src/config/app.ts`

- 将 `langPackCode` 默认值由 `'en'` 改为 **`'zh'`**，使应用启动时以简体中文语言包为默认请求/展示方向。

### `src/lang-zh.ts` / `src/langSign-zh.ts`

- **`lang-zh.ts`**：主界面与大量场景的中文翻译字符串，体量较大，作为本地/离线回退的文案来源（与 `VITE_LANG_PACK_VERSION` 及线上语言包配合）。
- **`langSign-zh.ts`**：登录、注册等 **langSign** 场景使用的中文片段。

### `src/countries-zh.ts`

- 国家/地区**中文名称**等数据，用于国家列表与选择器展示（由早期 `countries.zh.ts` 等命名演进而来）。

### `src/lib/langPack.ts`

核心改动集中在此文件，主要包括：

- **默认与回退语言**：`setLangCode` 等对空或未定义语言码的处理、偏向 **zh** 的默认与缓存逻辑。
- **`getCacheLangPackAndApply`**：对 **简体中文 / 本地语言包** 的强制或优先加载、保存与再次应用，保证与 `lang-zh` 等一致的体验。
- **`forceRefreshLanguageUI`**：在语言切换或应用后，批量刷新带 `i18n` / `data-i18n` 的 DOM，避免仅更新存储而界面不刷新。
- **语言热更新/状态**：`handleUpdateLangPack` 等与当前语言、存储版本比较时使用 `getLastRequestedLangCode()` 等 API，与官方分支保持兼容。
- **时间与 AM/PM**：12 小时制下的展示与时间格式相关行为（部分独立提交中曾标注「时间格式」类修改也落在此文件）。

### `src/components/sidebarLeft/tabs/language.tsx`

- 在语言设置页对语言列表做**补充**（如向 `languages2` 注入**简体中文**条目），使设置页能选到与本地包一致的选项。
- 用户切换语言后，通过 `I18n.getLangPackAndApply` 的回调中调用 `I18n.forceRefreshLanguageUI`（及短暂延迟），**立即刷新**相关 UI。

## 三、登录与 UI 行为

### `src/pages/pageSignQR.ts`

- 对 **qr-code-styling** 在部分环境下的绘制完成时机差异做了**兼容**：
  - 优先使用库内部的 **`_canvasDrawingPromise`**（若存在）等待首帧绘制；
  - 否则用 **`setInterval` 轮询 canvas / 2d context** 等兜底，再 `requestAnimationFrame` 继续流程。
- 与仅依赖 `_canvas._image` `load` 事件的写法不同，属**登录页二维码**场景的定制，减少白屏或过早结束轮询的问题。

## 四、其他说明

### 与上游的关系

- 本仓库会周期性 **merge `upstream/master`** 以同步官方能力；冲突解决时，**语言/中文相关**以本文档「一、」所述行为为准。

### 非功能类残留

- 若仍存在 **`debugger`**（如视频加载、视频泄漏处理等路径），仅用于本机调试，**发布前建议移除**。
- 个别文件可能仅有**空白/格式**差异，不视为功能定制。

### 版本信息

- 环境变量与构建号（如 `.env` 中 `VITE_VERSION_*`、`VITE_LANG_PACK_VERSION` 等）会随发布与上游同步变更，不逐项写入本文；以当前分支实际文件为准。
